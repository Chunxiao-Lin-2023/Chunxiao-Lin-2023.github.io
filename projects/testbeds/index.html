Real-time 10G Ethernet PC–FPGA testbed for distributed MIMO

Unpublished · 2026

An end-to-end, live channel-prediction loop for a distributed MIMO (DMIMO) system: a 4-antenna base station serves two 2-antenna users through a radio channel emulator, and an FPGA reservoir-computing accelerator predicts each user's channel frame by frame.

  • Software-defined radios carry the 4×2 DMIMO link through the channel emulator.
  • The host PCs stream channel estimates to the FPGA over 10 Gb/s Ethernet and get predictions back in real time.
  • A live visualizer shows the input channels, prediction error against outdated CSI, and end-to-end latency.
