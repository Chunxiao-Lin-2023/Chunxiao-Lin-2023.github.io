On-chip RLS learning for MIMO channel prediction

TCAD'262024 – 2026

A complete echo state network on one FPGA: inference and recursive-least-squares (RLS) training share the same DSP arrays, so the channel predictor retrains itself on chip.

3.87 µsper training + prediction step (Virtex-7, 100 MHz)
5.3×lower NMSE than the prior on-chip ESN learner
>1600×energy efficiency vs. a CPU (290× vs. a GPU)
264 Mb/son 64-dimensional channel data
  • An output-stationary systolic array computes the readout, about one MAC per DSP per cycle.
  • A three-stage pipelined RLS update takes 2L+4 cycles: O(L²) work, but time grows only linearly with the state size L.
